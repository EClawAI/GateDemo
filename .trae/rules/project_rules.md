# Trae AI 行为约束规则

## Git Commit 约束

**除非收到用户的明确命令，否则不要执行 git commit。**

### 具体规则

1. **禁止自动提交**
   - 在完成任何任务后，不要自动执行 `git commit`
   - 等待用户明确要求提交

2. **提交前的确认**
   - 如果需要提交代码，先询问用户是否需要提交
   - 除非用户明确要求，否则不要提交

3. **例外情况**
   - 用户主动要求提交
   - 用户使用 "提交"、"commit" 等关键词明确指示

## 实施方式

此规则适用于所有 git 操作：
- `git commit`
- `git add` + `git commit`
- 任何形式的自动提交

用户必须明确发出 "提交" 或 "commit" 命令后，才能执行相关操作。
