### 计划1.3：消息ID生成器

**任务清单**：

| 1.3.2 | 创建消息名常量类 | 定义所有消息名常量（如BattleModule、ChatModule） | 0.5天 | P0 |

**代码位置**：
- `common/protocol/MessageIdGenerator.java`
- `common/protocol/MessageIdRegistry.java`
- `proto/MessageIds.java`（生成）

**消息ID生成规则**：
```java
// 消息名示例：
// battle.move -> 0x_XXXX
// chat.send -> 0x_XXXX
// auth.login -> 0x_XXXX

// 使用FNV-1a 64位算法，取低16位
hash = fnv1a_64(messageName);
messageId = (int)(hash & 0xFFFF);
```

**关键设计**：
```java
// 推送策略伪代码
if (offlineMessageCount > threshold) {
    // Relogin模式：丢弃队列，通知Game重新登录
    discardOfflineMessages(playerId);
    notifyGameRelogin(playerId);
} else {
    // 正常模式：逐条推送
    pullAndPushOneByOne(playerId);
}
```
